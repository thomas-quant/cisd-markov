Widen `_annotate_swing_smt_from_events` in `cisd_data.py` so the Swing-SMT annotation (a) carries the price/lifecycle fields the scanner already returns, (b) fixes the already-invalidated-at-`t` tagging bug (D-01/D-02/D-03/D-03a), and (c) adds the two geometry columns `smt_block_size_atr` (D-04) and `cisd_in_smt_block` (D-05), gated to the matched-SMT population (D-05a). Purpose: Stop discarding the lifecycle data the scanner returns and stop crediting SMTs that were already dead by the CISD bar, so the published `w/ SMT` rate becomes honest (SC1). Precompute geometry (SC3) and the survived/broke horizon flag (SC4) once, in the vectorized annotation, so the compute layer only reads precomputed columns (repo architecture invariant).
Output: A widened `_annotate_swing_smt_from_events` producing the new columns, plus `tests/test_smt_invalidation.py` locking the validity and geometry semantics with held-out assertions.
</objective>
