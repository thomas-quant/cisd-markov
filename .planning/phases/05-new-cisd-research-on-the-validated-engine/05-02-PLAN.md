<objective>
Ship RES-02: a single multi-bar `post_cisd_context` barrier study on the refactored engine, reporting through the validation harness (n + Wilson CI, IS/OOS) from the start.

The study isolates the `candle2_gap_context` / `post_cisd_reversal_context` regime: a CISD whose `candle[1]` **failed** to close beyond `candle[0]`'s extreme (weak follow-through), then bucketed by `candle[2]`'s gap direction relative to the CISD (gap-with / gap-against / flat). The reversal context is the failed-`candle[1]` + gap-against bucket — it is a BUCKET of this one analysis, not a separate analysis (D-05). Continuation is measured AFTER `candle[2]` via the re-anchored barrier (lookahead starts at `idx+2`) using `candle[0]`'s own high/low, so RES-02 is inherently forward-anchored with no in-window variant (D-06). The outcome metric is the continuation hit-rate only for this first pass (the explicit reversal barrier is a deferred optional extension per CONTEXT discretion).

This plan also homes Reading B from D-04 — `candle[2]` closes beyond `candle[1]`'s wick — as a separate added cut inside RES-02, never duplicated in 05-01 and never multiplied into either core (avoiding a bucket explosion the `n>=50` gate would suppress).

Purpose: Complete the new-research phase with the second honest, harness-native study. The gap dimension is expected to be Daily-dominant; intraday gap buckets collapse to ~flat and are flagged below-n but stay visible (D-08, D-09).
Output: New precomputed feature columns, a `compute_post_cisd_context` + `chart_post_cisd_context` pair, registry entries, a re-export, harness wiring, and locking unit tests — all additive.

Candle indexing convention: `candle[-1]` = bar before the CISD (`prev_*`), `candle[0]` = the CISD bar, `candle[1]` = next bar, `candle[2]` = two bars after.

This plan depends on 05-01: it reuses the forward re-anchored barrier helper (`barrier_hit_forward` / the `start_offset` parameterization) and the candle[1] feature columns introduced there, and edits the SAME six modules — hence Wave 2 to avoid concurrent edits to the shared files.
</objective>
