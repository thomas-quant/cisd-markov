<objective>
Create the D-09 verdict-computation script that mirrors `scripts/build_reconcile_findings.py`'s "read manifests, compute verdict, write CSV" shape but implements the harder, strictly-ANDed corrected bar (D-02) scoped only to the two post-CISD studies (D-01). It reads the discovery, sacred-OOS, and walk-forward manifests, and for each bucket decides whether it clears the corrected evidence bar: discovery `corrected_pass` is True AND walk-forward `wf_verdict == "wf-robust"` AND the sacred-OOS rate is on the same non-boundary side of 0.50 as the discovery rate. It then rolls the per-bucket verdicts up per post-CISD tag by strict majority (D-03), retaining the finest-granularity per-bucket data as well.

Purpose: This is the go/no-go engine that gates Phase 8. Per D-09 the numbers are script-generated (deterministic), while the README narrative (07-03) is hand-authored from them. This plan produces only the script and its unit tests — it is fixture-tested and does NOT run against real manifests (those still lack the reversal tags until 07-03 regenerates them).

Output: `scripts/build_post_cisd_verdict.py`; two output-CSV schemas; `tests/test_post_cisd_verdict.py`.
</objective>
