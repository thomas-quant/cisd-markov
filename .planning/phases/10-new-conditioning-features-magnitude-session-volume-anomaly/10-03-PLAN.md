<objective>
Add the intraday-only session/time-of-day analysis (SC2) and the one genuinely new mechanism this phase needs (D-14): a per-analysis timeframe allow-list on `ANALYSIS_META` consumed by both the validation manifest loop and the chart figure dispatch, so the session analysis runs on 15min and 1H only. compute_session itself stays TF-agnostic — the scoping is registry-driven, reusable, and lowest-touch.

Purpose: A session tag on a Daily or 4H bar spans multiple sessions and is economically meaningless; registering it there would only add below-n cells that dilute the global BH-FDR family. The allow-list keeps the session analysis honest and parsimonious while remaining a clean, reusable mechanism.

Output: `cisd_barriers.py` (compute_session + applies_to field + registry), `cisd_charts.py` (chart_session + figure guards), `scripts/build_validation.py` (tf_keys filtering), extended tests.
</objective>
