| git index -> repository history | Untracking output/ changes what future commits carry |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-SC | Tampering | CI pip install -r requirements.txt on a hosted runner | mitigate | requirements.txt (from 01-01) pins exact versions of the canonical, already-vetted scientific Python stack; no new packages. Pin actions/checkout and actions/setup-python to known major tags to avoid pulling a moving/poisoned action. |
| T-02-01 | Information Disclosure | .env files containing local paths/secrets | mitigate | Task 1 adds .env / .env.local to .gitignore so real env files are never committed; only .env.example (no secrets) is tracked. |
| T-02-02 | Repudiation | Generated output/ blobs polluting history | accept | Already-committed blobs remain in past history (acceptable for a solo research repo); going forward output/ is untracked and ignored so no new blobs are added. |
</threat_model>
