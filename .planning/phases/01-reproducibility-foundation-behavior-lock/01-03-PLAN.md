Behavior-preserving capture rule: The characterization test locks the CURRENT CODE'S output. The README values listed in Task 2 are the reference set. Run the real pipeline locally, capture the actual computed rates, and assert them to the README's stated precision. If the current code's output disagrees with a README value, that is a discrepancy to SURFACE in the SUMMARY (the README may be stale) — never edit the code to "fix" it and never silently weaken an assertion.
