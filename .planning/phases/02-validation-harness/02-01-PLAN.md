<objective>
Implement the sacred date holdout infrastructure: compute and freeze OOS_START as a committed constant (the 70th-percentile date of the shared NQ∩ES daily calendar), add MIN_N=50 and CI_LEVEL=0.95 to cisd_analysis.py, and create scripts/build_validation.py as the harness entry point with a discovery-on-train default path and an explicit --oos path that prints a loud warning. Write data-free unit tests that lock the slicing contract.

Purpose: The holdout is the foundation of every trust claim in Phase 2-5. OOS_START must be computed from the actual data once and then frozen — future data appends must not silently shift the boundary. The default path must make it hard to accidentally burn the OOS evaluation; the --oos path must make the deliberateness visible.

Output: cisd_analysis.py gains three additive constants; scripts/build_validation.py is a new runnable harness that writes output/validation_slices.csv on a live data run; tests/test_validation_harness.py has data-free slicing tests. No existing output artifact is touched.

Behavior-preserving constraint: No changes to any existing compute_* function, barrier_hit, or any default code path in main(). The three new constants are purely additive — full-history runs via python3 cisd_analysis.py are byte-identical to before this plan.
</objective>
