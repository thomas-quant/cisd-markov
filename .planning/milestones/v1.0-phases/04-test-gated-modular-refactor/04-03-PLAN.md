<objective>
Replace the `iterrows()` + `df.index.get_loc(ts)` hot-loop pattern in `_annotate_cisd_research` (the outer CISD loop) and in all 14 `compute_*` functions with the `np.flatnonzero` + NumPy-array-indexing pattern proven in `scripts/build_expectancy.py:build_event_r_multiples()`. Accumulate per-row results in plain Python lists/dicts indexed by integer position, then bulk-assign columns after the loop.

Purpose: The annotation pass and every compute function iterate DataFrame rows in Python and call `index.get_loc(ts)` per event — each `get_loc` is a hashtable lookup on the DatetimeIndex (62 combined occurrences). Vectorizing the position lookup removes the hottest research code path (REFAC-03).

Output: Vectorized `_annotate_cisd_research` and 14 compute functions, producing BIT-IDENTICAL numbers. The characterization tests are the automatic verification gate — no manual output comparison.
</objective>
