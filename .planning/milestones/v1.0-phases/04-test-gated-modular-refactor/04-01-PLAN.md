<objective>
Split the 1,380-line god-file `cisd_analysis.py` into three focused modules — `cisd_data.py` (load/resample/prepare/annotate/SMT), `cisd_barriers.py` (barrier logic, constants, 14 compute functions, ANALYSES registry), and `cisd_charts.py` (14 chart functions, figure/CSV builders) — and reduce `cisd_analysis.py` to a thin orchestrator that re-exports the full public API and keeps `main()`.

Purpose: Eliminate the god-file architecture (REFAC-01) so every new analysis no longer forces edits to a single monolithic file, while preserving the exact public import surface that 7 scripts and 7 test files depend on.

Output: `cisd_data.py`, `cisd_barriers.py`, `cisd_charts.py` (new), plus `cisd_analysis.py` rewritten as a re-export shim + CLI. Zero behavioral change — characterization tests stay green.
</objective>
